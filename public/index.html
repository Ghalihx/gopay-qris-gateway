Alur Cara Kerja Integrasi:
1. Generate Tagihan

Aplikasi atau bot Anda memanggil endpoint /api/create dengan nominal bayar dan header API Key.

2. Tampilkan QRIS

Kirimkan gambar QRIS dinamis dan total nominal yang sudah ada kode uniknya ke pembeli.

3. Konfirmasi Lunas

Sistem memeriksa status ke /api/check/:check_id setiap beberapa detik hingga berstatus PAID.

1. Create Transaction (Header x-api-key Wajib)

Panggil endpoint berikut dengan header x-api-key: YOUR_KEY:

curl -X GET "/api/create?amount=10000" \
  -H "x-api-key: YOUR_API_KEY"

Parameter query opsional: ¬e=NamaBarang dan &static_qr=000201...

2. Check Status (Polling Pembayaran)

GET /api/check/:check_id

3. Direct Image QR (PNG)

GET /api/qr/:check_id.png
